# CreaDigital Boyacá - Prototipo básico

Versión ligera (HTML/CSS/JS) orientada a demostración y pruebas en entorno controlado.

## Ejecutar localmente
Abrir `index.html` en cualquier navegador moderno.

## Estructura
- index.html: página principal
- gallery.html: galería de obras (datos simulados en gallery.html)
- css/: estilos
- js/: scripts
- assets/: imágenes de demo

## Instrucciones para subir a GitHub
1. git init
2. git add .
3. git commit -m "Initial basic prototype"
4. Crear repo en GitHub y git remote add origin <URL>
5. git push -u origin main
