## Instrucciones rápidas
1. Descomprimir el ZIP en su carpeta local.  
2. Revisar `Analisis_Requerimientos.md` para requisitos y plan de desarrollo.  
3. Subir/commitar la carpeta `docs/` y los archivos al repositorio principal en GitHub.  
4. Para la versión React: configurar `.env.local` con las variables de Firebase antes de `npm start`.
